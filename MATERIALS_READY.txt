💻 COMMAND QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════

Get Started:
  chmod +x scripts/*.sh        # Make scripts executable
  chmod +x demo.sh             # Make demo executable

System Control:
  ./scripts/start.sh            # Start entire system
  ./scripts/stop.sh             # Stop entire system
  ./scripts/reset.sh            # Full reset (destructive)

Status & Info:
  python3 controller/cli.py status    # System status
  python3 controller/cli.py info      # System info (JSON)

User Management:
  python3 controller/cli.py user create alice      # Create user
  python3 controller/cli.py user enter alice       # Access user shell
  python3 controller/cli.py user delete alice      # Delete user
  python3 controller/cli.py user list              # List users

Demo & Testing:
  ./demo.sh                                        # Full automated demo
  python3 controller/cli.py launch-shell           # Admin shell
  python3 controller/cli.py logs mini-os-logger    # View logs
